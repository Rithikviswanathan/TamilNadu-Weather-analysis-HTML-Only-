What the metrics mean

  • R²: fraction of target variance explained; close to 1 is strong on the evaluation split.
  • RMSE / MAE: temperature prediction error in °C; lower is better.
  • Accuracy: proportion of correct rain/dry classifications; can hide class imbalance.
  • F1 / ROC-AUC: balance precision-recall and ranking discrimination, respectively.

Project notes

About this standalone build

What was in the ZIP

The source project is a Python Flask application, not a pure static website. It includes Flask routes and APIs, data preparation and model-training scripts, scikit-learn model pickle files, SQLite persistence, templates, CSS, JavaScript charts, and historical CSV data.

What this single file preserves

  • Responsive dashboard, city selector, current-condition summary, forecast cards and charts.
  • Forecast page with 3–14 day options and daily table.
  • Historical-data table with city and date filters, based on embedded source records.
  • Saved model-performance metrics and confusion matrix.
  • All CSS and JavaScript embedded in this HTML; no build tools or external libraries required.

Important limitations

  • A browser-only HTML file cannot run the original Python/scikit-learn models, Flask API routes, or SQLite database.
  • Live weather requires a weather provider API and usually a backend to protect the API key. This file intentionally does not claim to show live weather.
  • The forecast shown here is a lightweight seasonal baseline with small deterministic variation, for demonstration only.
  • To run the actual machine-learning application with the original models, use the Flask project and its Python dependencies; this file is a portable frontend/demo, not a replacement for the backend.
